# 바다 길찾기 서비스 (이름은 아직 안 정함)

요트·배로 갈 때 바닷길(방향, 거리, 시간)과 도착지 근처의 배 댈 곳(정박할 곳)을 알려 주는 웹 서비스입니다.
이 폴더에서는 이 서비스만 다룹니다. 같은 날 함께 만든 서비스: `../바다이야기/`, `../오늘의바다/`.

## 함께 일하는 사람
- 사용자는 초등학교 6학년 학생(또는 선생님)입니다. 쉬운 말로 짧게 설명하고, 어려운 용어는 풀어서 말해 주세요.
- 무엇을 바꿨는지, 어디를 눌러 보면 확인할 수 있는지 매번 알려 주세요.
- 요청이 애매하면 마음대로 정하지 말고 한 가지만 되물어 주세요.
- 지금 화면은 "기본 틀"입니다. 학생들이 보고 기능을 더하거나 뺄 예정입니다 (2026-10-23 선생님).

## 찾은 문제 (2026-10-23)
- 요트·배로 이동할 때 어떻게 가야 할지, 어디에 정박할지 모른다 (바다 내비게이션).

## 만드는 방식
- 설치 없이 브라우저에서 바로 열리는 웹 페이지 (`index.html` 한 파일).
- **로그인 없이** 누구나 씀. 서버에 저장하는 것이 없음. 나중에 "정박 장소 공유"처럼 저장할 기능을 더하면 메신저·잉스타와 같은 AWS 서버와 계정을 쓰면 됨 (`../바다이야기/index.html`의 로그인 부분을 가져오기).
- 지도와 배 댈 곳 찾기는 카카오맵 (길찾기와 같은 JavaScript 키, 장소 검색). 등록한 도메인 `https://rudghch.github.io`에서만 보임. 앱 안 미리보기에서는 지도가 안 뜨니 웹에 올린 뒤 확인.
- 도착지 바다 상태는 무료 서버 Open-Meteo (키 필요 없음, 오늘의 바다와 같은 방법). 예상값임.
- "🌊 도착지 바다 자세히 보기"는 오늘의 바다를 새 창으로 열고 주소 끝에 `#위도,경도`를 붙여 보냄.
- 길은 곧은 선이라 섬·바위·얕은 곳을 피하지 않음. 화면에 "진짜로 배를 탈 때는 선장님과 해도를 따라야 한다"는 안내가 있음.
- 실제 서비스의 이름과 로고는 쓰지 않습니다. 서비스 이름은 학생들이 정합니다.

## 학생들이 바꾸기 쉬운 곳 (`index.html`)
- `BOATS`: 탈것과 빠르기 (카약 3, 요트 6, 여객선 15, 모터보트 25노트)
- `DOCK_WORDS`, `DOCK_RADIUS`: 배를 댈 곳을 찾을 때 카카오맵에 묻는 말과 거리(20km)
- `DOCK_SKIP`: 배 댈 곳 결과에서 뺄 이름 (주차장, 호텔, 웨딩홀 등이 섞여 나와서 넣음)

## 미리보기와 웹에 올리기
- 미리보기: 작업 폴더의 `.claude/launch.json`에 있는 `startup-preview`로 열고 `http://localhost:8765/바다길찾기/`로 감. 지도는 안 뜸.
- 다 만들면 묻지 않고 GitHub에 올림 (선생님 요청, 2026-10-23).
  - 주소: https://rudghch.github.io/startup/바다길찾기/
  - `git add .` (이 폴더 안에서 실행) → `git commit -m "바다 길찾기: 바꾼 내용 한 줄"` → `git push`
  - `git`을 찾지 못하면 `C:\Program Files\Git\cmd\git.exe`를 씀. 이 폴더의 변경만 올리고, 다른 팀 폴더는 건드리지 않음.
  - 컴퓨터 안의 처음 화면(`../index.html`)에는 아직 안 올린 섬지도 카드도 들어 있으니, 처음 화면을 올릴 때 섬지도 카드는 빼고 올리거나 먼저 물어봄.
