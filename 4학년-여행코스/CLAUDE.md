# 4학년 여행 코스 서비스

4학년 학생들의 "추천 여행 코스" 웹 서비스입니다. 이 폴더에서는 이 서비스만 다룹니다.

## 함께 일하는 사람
- 사용자는 초등학생(또는 선생님)입니다. 쉬운 말로 짧게 설명하고, 어려운 용어는 풀어서 말해 주세요.
- 무엇을 바꿨는지, 어디를 눌러 보면 확인할 수 있는지 매번 알려 주세요.
- 요청이 애매하면 마음대로 정하지 말고 한 가지만 되물어 주세요.

## 만드는 방식
- 설치 없이 브라우저에서 바로 열리는 웹 페이지 (HTML, CSS, JavaScript, `index.html` 한 파일).
- 지도는 카카오맵(길찾기와 같은 JavaScript 키). 등록한 도메인 `https://rudghch.github.io`에서만 보임. 앱 안 미리보기에서는 지도가 안 뜨니 웹에 올린 뒤 확인.
- 개인정보 규칙: 명부에는 이름(별명도 됨)만 넣고, 사진에 얼굴이 나오지 않게 안내합니다. 이 사이트는 누구나 볼 수 있습니다.

## 지금까지 만든 것
- 반 코드 화면: 코드를 적어야 들어감. 코드는 이 컴퓨터에 기억함. 선생님 코드는 창을 닫으면 잊음
- 처음 화면: 학생 명부 카드. 누르면 그 친구의 추천 여행 코스로 감 (주소 `#/s/번호`). 선생님 코드를 적으면 아래에서 이름을 한 줄에 한 명씩 넣고, 카드의 "빼기"로 뺌(코스와 사진도 같이 지워짐)
- 코스 보기: 왼쪽 지도에 번호 동그라미와 점선, 오른쪽에 코스 이름·소개와 곳마다 이름·주소·설명·사진. 번호나 이름을 누르면 지도가 그곳으로 감. 사진은 누르면 크게 보임
- 코스 만들기·고치기: 이름으로 찾아 고르거나 "지도에서 찍기"로 곳을 넣음(20곳까지). 곳마다 이름, 설명(500글자), 사진(4장까지, 1280px로 줄임). ▲▼로 순서 바꾸기, 빼기, 저장하기. 저장 안 하고 나가면 물어봄. 사진 올리는 중에는 저장이 막힘
- 서버 주소(`API_URL`)가 비어 있으면 "연습 중" 모드: 이 컴퓨터(IndexedDB)에만 저장되고 다른 컴퓨터에서는 안 보임

## 서버 (아직 안 만듦)
- `클로드코드\메신저-서버-준비\server.yaml`에 `TripApi`(여행 코스 서버)를 더해 둠. 메신저 팀과 같은 표·보관함을 쓰고 게시판과 다른 줄(`pk`가 `TRIP`)에 저장
- AWS에서 스택 업데이트할 때 **TripClassCode**(반 코드)와 **TripTeacherCode**(선생님 코드, 서로 다르게)를 적고, 출력의 **TripUrl**을 `index.html`의 `API_URL`에 넣으면 연결됨. 두 코드가 비어 있으면 서버는 꺼진 채로 있음. 순서는 `서버-만들기.md`의 다른 기능 업데이트와 같음
- 코드는 비밀이라 웹 페이지에 넣지 않음. 서버에서만 검사함

## 아직 확인 못 한 것
- 지도(찾기, 지도에서 찍기, 번호 동그라미, 선)는 미리보기에서 안 떠서 웹에 올린 뒤 봐야 함
- 진짜 서버 연결 (연습 모드로만 시험함)
