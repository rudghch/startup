# 메신저 서비스 (카카오톡과 비슷한 서비스)

초등학교 6학년 학생들이 직접 기획하고 만드는 메신저 웹 서비스입니다.
이 폴더에서는 메신저 서비스만 다룹니다.

## 함께 일하는 사람
- 사용자는 초등학교 6학년 학생입니다. 쉬운 말로 짧게 설명하고, 어려운 용어는 풀어서 말해 주세요.
- 무엇을 바꿨는지, 어디를 눌러 보면 확인할 수 있는지 매번 알려 주세요.
- 요청이 애매하면 마음대로 정하지 말고 한 가지만 되물어 주세요.

## 만드는 방식
- 설치 없이 브라우저에서 바로 열리는 웹 페이지로 만듭니다 (HTML, CSS, JavaScript).
- 계정과 대화, 게시물은 AWS 서버에 저장합니다. 그래서 다른 컴퓨터의 친구와도 주고받을 수 있습니다.
- 한 번에 기능 하나씩 만들고, 동작을 확인한 뒤 다음 기능으로 넘어갑니다.
- 실제 서비스의 이름과 로고는 쓰지 않습니다. 서비스 이름은 학생들이 정합니다.
- 실제 이름, 전화번호, 사진 같은 개인정보는 넣지 않습니다. 친구 이름은 지어낸 이름을 씁니다.

## 지금까지 만든 것
(기능을 하나 완성할 때마다 여기에 한 줄씩 적기)
- 대화창: 메시지를 쓰고 보내기 버튼이나 엔터로 보냄 (`index.html` 한 파일)
- 계정: 아이디(2~12글자 별명)와 비밀번호(4글자부터)로 가입하고 로그인함. 가입할 때 선생님이 정한 가입 코드가 필요함. 로그인은 그 브라우저에 기억되고 "로그아웃"으로 나감
- 계정별 대화: 모든 계정이 대화방 하나에 함께 참여함. 내 메시지는 오른쪽, 다른 계정 메시지는 왼쪽. 3초마다 서버에 새 메시지를 물어봄
- 게시물: 글과 사진·영상을 올리고, 내가 올린 것만 삭제함. 사진은 1280px로 줄이고 영상은 30MB까지, 파일은 6개까지
- 서버: AWS(Lambda + DynamoDB + S3)를 씀. 서버를 만드는 파일과 설명서는 공개 폴더 밖인 `클로드코드\메신저-서버-준비\`에 있음 (`server.yaml`, `서버-만들기.md`). 계정 주인이 AWS 화면에서 직접 만들어야 하고, 나온 서버 주소(ServerUrl)를 `index.html`의 `API_URL`에 넣으면 연결됨. 주소가 비어 있으면 "서버가 아직 연결되지 않았어요" 화면이 나옴
- 서버는 잉스타(사진공유)와 함께 쓸 수 있게 만들었음 (게시판 이름 `board`만 다르게 보냄). 잉스타 연결은 사진공유 폴더에서 따로 함
- 서버 만든 날: 2026-10-06, AWS 서울 지역, CloudFormation 스택 이름 `messenger`. 서버 주소는 `index.html`의 `API_URL`에 넣어 둠. 가입 코드는 학생이 직접 정했고 Claude는 모름 (묻거나 파일에 적지 않기)
- 진짜 서버에서 확인한 것: 서버 연결, 틀린 로그인 막기, 틀린 가입 코드 막기, 로그인 안 한 사람 막기. 아직 확인 못 한 것: 진짜 가입, 대화 주고받기, 사진·영상 올리기 (가입 코드가 있어야 해서 학생이 직접 해 봐야 함)
- 미리보기: 작업 폴더의 `.claude/launch.json`에 있는 `startup-preview`로 열고 `http://localhost:8765/메신저/`로 감 (파일을 그냥 열면 버튼이 동작하지 않는 멈춘 화면만 보임)
