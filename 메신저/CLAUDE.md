# 메신저 서비스 (카카오톡과 비슷한 서비스)

초등학교 6학년 학생들이 직접 기획하고 만드는 메신저 웹 서비스입니다.
이 폴더에서는 메신저 서비스만 다룹니다.

## 함께 일하는 사람
- 사용자는 초등학교 6학년 학생입니다. 쉬운 말로 짧게 설명하고, 어려운 용어는 풀어서 말해 주세요.
- 무엇을 바꿨는지, 어디를 눌러 보면 확인할 수 있는지 매번 알려 주세요.
- 요청이 애매하면 마음대로 정하지 말고 한 가지만 되물어 주세요.

## 만드는 방식
- 설치 없이 브라우저에서 바로 열리는 웹 페이지로 만듭니다 (HTML, CSS, JavaScript).
- 첫 버전은 서버 없이 한 컴퓨터 화면 안에서 동작합니다. 친구와 대화 내용은 가짜 예시 데이터로 만듭니다.
- 한 번에 기능 하나씩 만들고, 동작을 확인한 뒤 다음 기능으로 넘어갑니다.
- 실제 서비스의 이름과 로고는 쓰지 않습니다. 서비스 이름은 학생들이 정합니다.
- 실제 이름, 전화번호, 사진 같은 개인정보는 넣지 않습니다. 친구 이름은 지어낸 이름을 씁니다.

## 미리보기와 웹에 올리기
- 기능을 만들거나 고칠 때마다 미리보기로 열어서 학생이 바로 확인할 수 있게 합니다.
- 시작 화면은 이 폴더의 `index.html`입니다. 지금은 "만드는 중" 임시 화면이 들어 있으니 첫 버전을 만들 때 바꿉니다.
- 학생이 "올려줘"라고 하면 이 폴더의 변경만 GitHub에 올립니다. 다른 팀 폴더는 건드리지 않습니다.
  - `git add .` (이 폴더 안에서 실행) → `git commit -m "메신저: 바꾼 내용 한 줄"` → `git push`
  - `git`을 찾지 못하면 `C:\Program Files\Git\cmd\git.exe`를 씁니다.
- 올린 뒤 1~2분 지나면 크롬북에서 새로고침해 확인할 수 있습니다.

- 올리기 전에 실제 이름, 얼굴 사진, 전화번호 같은 개인정보가 없는지 확인합니다. 이 사이트는 누구나 볼 수 있습니다.
