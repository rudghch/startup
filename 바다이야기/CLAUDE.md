# k-island map 서비스 (예전 이름: 바다 이야기 → 물고기가 무꼬?!)

섬과 바다의 사진·영상을 모으고, 찍은 곳을 지도에 표시하는 웹 서비스입니다.
이 폴더에서는 이 서비스만 다룹니다. 같은 날 함께 만든 서비스: `../오늘의바다/`, `../바다길찾기/`.

## 서비스 이름과 로고
- k-island map (2026-10-23에 "바다 이야기" → "물고기가 무꼬?!" → "k-island map"으로 바꿈. 폴더 이름과 주소는 그대로 `바다이야기`)
- 로고 `logo.png`: 학생이 그린 섬 그림(바다 위 초록 섬, 회색 봉우리, 빨간 위치 표시). 밝은 바탕을 가장자리부터 투명하게 지우고 256px로 줄임. 맨 위 제목, 브라우저 탭 아이콘, 처음 화면 카드에 씀. (그 전 로고였던 하늘색 물고기 그림은 바꾸면서 지움)

## 함께 일하는 사람
- 사용자는 초등학교 6학년 학생(또는 선생님)입니다. 쉬운 말로 짧게 설명하고, 어려운 용어는 풀어서 말해 주세요.
- 무엇을 바꿨는지, 어디를 눌러 보면 확인할 수 있는지 매번 알려 주세요.
- 요청이 애매하면 마음대로 정하지 말고 한 가지만 되물어 주세요.
- 지금 화면은 "기본 틀"입니다. 학생들이 보고 기능을 더하거나 뺄 예정입니다 (2026-10-23 선생님).

## 찾은 문제 (2026-10-23)
- 섬과 바다에 대한 정보가 부족하다. 어업 도구에 문제가 생겨도 해결하기 어렵고, 모르는 바다 생물을 알려 줄 곳이 없다.
- 해결: 섬마다 사진·영상을 올리고, 찍은 곳을 지도에 표시한다. 모르는 것은 "❓ 이게 뭐예요?"로 묻고 댓글로 답한다.
- 섬지도(`../섬지도/`)와 비슷함. 섬지도는 바라본 방향까지 저장하고, 이 서비스는 영상·종류·댓글이 있음. 게시판이 달라서 서로의 사진은 안 보임.

## 만드는 방식
- 설치 없이 브라우저에서 바로 열리는 웹 페이지 (`index.html` 한 파일).
- 서버는 메신저·잉스타·섬지도와 같은 AWS 서버, 같은 계정(`messenger.token`)을 씀. 로그인해야 들어감. 서버 파일과 설명서는 공개 폴더 밖 `클로드코드\메신저-서버-준비\`에 있음.
- 서버는 고치지 않고 게시판만 나눠 씀. 글 칸에 JSON을 넣음:
  - `seapost`: 게시물 `{"island","kind","text","lat","lng"}` + 사진·영상 6개까지
  - `q`+게시물 번호를 글자로 바꾼 것(0→a…9→j, 20글자까지): 그 게시물의 댓글
  - 서버가 게시판마다 최근 100개만 주므로 게시물·댓글도 각각 최근 100개까지만 보임
  - `w`+원래 사진 주소를 영어 소문자 19글자로 바꾼 것: 🌐 인터넷 사진의 댓글
- 🌐 인터넷 사진은 `internet-photos.json`에 들어 있음 (서버가 아니라 이 폴더의 파일). 사진 파일은 위키미디어 공용(`upload.wikimedia.org`, `thumb.wikimedia.org`)에서 바로 불러옴.
  - 위키미디어 공용(commons.wikimedia.org)은 누구나 쓸 수 있게 허락된 사진만 모아 두는 곳. 허락 종류: CC0·퍼블릭 도메인(저작권 걱정 없음), CC BY·CC BY-SA·출처 표시·공공누리 1유형(찍은 사람과 허락 종류를 꼭 함께 보여 주면 됨)
  - 그래서 카드와 크게 보기 창에 꼭 "사진: 찍은 사람 · 허락 종류 · 원래 사진 보기"를 보여 줌. 이 부분은 지우지 않음
  - 모은 방법 (2026-10-23): 위키미디어 공용의 분류(Odongdo, Dolsan Island(+향일암·돌산공원·돌산대교·거북선대교), Geomun Island, Jangdo (Yeosu), Janggundo)와 검색(금오도, 낭도, 사도, 개도)으로 157장을 찾고, 눈으로 보고 85장을 고름. 뺀 것: 옛날 지도·바다 지도, 시청·학교 같은 건물, 기념비·묘지, 사람 얼굴이 보일 수 있는 사진, 겹치는 사진. 설명은 한글로 새로 씀. 사진에 위치 정보가 없으면 섬 가운데 둘레에 조금씩 흩어 놓음
  - 위키미디어에 사진이 없는 여수 섬: 백도(거문도 사진에 멀리 보임), 하화도, 안도, 연도, 백야도, 경도, 적금도 등
  - 사진을 더 넣으려면 같은 모양으로 `internet-photos.json`에 줄을 더함 (island, kind, text, lat, lng, photo, page, license, licenseUrl, artist)
- 👀 사람들이 본 생물은 `island-life.json` (이 폴더의 파일, 2026-10-28). 섬 12곳(돌산도, 향일암, 오동도, 장군도, 장도, 금오도, 개도, 하화도, 사도, 낭도, 거문도, 백도)과 바다 2곳(가막만, 여자만), 생물 110가지
  - 모은 방법: Claude가 블로그·유튜브·카페(커뮤니티)·기사·공식 누리집을 검색해서 읽고, 생물·때(달)·자리·잡는 방법·한 줄 설명을 **우리 말로 짧게 새로 씀** (글을 그대로 옮기면 저작권 문제라서 옮기지 않음). 생물마다 `src`에 출처 번호가 있고, 화면에서 출처 링크로 원래 글을 봄
  - 유튜브 출처 5개는 유튜브가 허락하는 퍼가기(`youtube-nocookie.com/embed`)로 화면 안에서 봄 (2026-10-28 영상이 있는지 확인함)
  - 진짜 "퍼오기"(검색 결과를 그때그때 가져오기)는 네이버·유튜브 검색 키와 서버가 필요해서 안 함. 대신 섬·생물마다 "📝 네이버 블로그 / ▶️ 유튜브 / 💬 네이버 카페" 검색을 새 창으로 여는 버튼을 둠
  - 조심: 오동도 방파제는 지금 낚시 금지라는 글이 있어 "예전 기록"으로 적고 `warn`으로 안내. 장군도 물고기는 맞은편 중앙동 선착장 이야기, 장도는 앞 웅천 해변 이야기. 백도·가막만·여자만 자리는 어림값. bfg-fishing.com 글(자동으로 만든 듯한 안내)만 출처인 것은 약한 정보. 감성돔 금어기(5월)는 나라 규칙
  - 더 넣으려면 같은 모양으로 places에 섬을 더함: name, kind(island/sea), lat, lng, summary, warn(없어도 됨), creatures[{name, emoji, months, where, how, note, src}], sources[{title, url, type: blog/youtube/cafe/news/official}], thin
- 지도는 카카오맵 (길찾기와 같은 JavaScript 키). 등록한 도메인 `https://rudghch.github.io`에서만 보임. 앱 안 미리보기에서는 지도가 안 뜨니 웹에 올린 뒤 확인.
- 나쁜 말 막기(`BAD_WORDS`)는 잉스타·섬지도와 같은 목록. 게시물·댓글에 씀.
- 한 번에 기능 하나씩 만들고, 동작을 확인한 뒤 다음 기능으로 넘어갑니다.
- 실제 서비스의 이름과 로고는 쓰지 않습니다. 서비스 이름은 학생들이 정합니다.
- 개인정보 규칙: 얼굴이 나온 사진, 실명, 전화번호, 집 주소는 넣지 않게 안내함. 이 사이트는 누구나 열 수 있음.

## 학생들이 바꾸기 쉬운 곳 (`index.html`)
- `STORY_KINDS`: 올릴 때 고르는 종류 (섬 풍경, 놀거리, 리뷰, 바다 생물, 어업 도구, 이게 뭐예요?, 기타)
- `WHERE_RADIUS_KM`(사는 생물: 누른 곳 둘레 20km), `ISLANDS`(섬 보기 바로 고르는 섬 19곳), `SPOT_STORY_KM`(로드뷰 둘레 이야기 3km), `ISLE_DOT_LEVEL`(이 단계보다 확대하면 이야기 없는 섬 이름표도 보임)
- `MAX_TEXT`(설명 500글자), `MAX_FILES`(6개, 서버가 받는 수), `MAX_VIDEO`(30MB), `FIRST_PLACE`(처음 지도 자리, 여수 바다)
