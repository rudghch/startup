# 새 서비스 (이름은 아직 안 정함) — 섬과 바다 정보 서비스

초등학교 6학년 학생들이 직접 찾은 문제를 풀려고 만드는 웹 서비스입니다.
이 폴더에서는 이 서비스만 다룹니다.

- 지금 화면은 "기본 틀"입니다. 학생들이 보고 기능을 더하거나 뺄 예정입니다 (2026-10-23 선생님).

## 찾은 문제 (2026-10-23)
1. 섬과 바다에 대한 정보가 부족하다. 어업 도구에 문제가 생겨도 해결하기 어렵고, 모르는 바다 생물을 알려 줄 곳이 없다.
   → 해결: 섬마다 사진·영상을 올리고, 찍은 곳을 지도에 표시한다.
2. 바닷가에 놀러 가면 실시간 정보를 모른다. 물이 언제 차는지(물때), 위험한지, 해파리·상어, 수온, 수영해도 되는지, 적조.
3. 요트·배로 이동할 때 어떻게 가야 할지, 어디에 정박할지 모른다 (바다 내비게이션).
- 섬지도(`../섬지도/`)와 1번 문제가 비슷함. 섬지도는 바라본 방향까지 저장하고, 이 서비스는 영상·종류·댓글이 있음. 게시판이 달라서 서로의 사진은 안 보임.

## 만드는 방식
- 설치 없이 브라우저에서 바로 열리는 웹 페이지 (`index.html` 한 파일). 맨 위 탭 3개가 문제 3개.
- 서버는 메신저·잉스타·섬지도와 같은 AWS 서버, 같은 계정(`messenger.token`)을 씀. 로그인해야 들어감. 서버 파일과 설명서는 공개 폴더 밖 `클로드코드\메신저-서버-준비\`에 있음.
- 서버는 고치지 않고 게시판만 나눠 씀. 글 칸에 JSON을 넣음:
  - `seapost`: 섬과 바다 이야기 `{"island","kind","text","lat","lng"}` + 사진·영상 6개까지
  - `q`+게시물 번호를 글자로 바꾼 것(0→a…9→j, 20글자까지): 그 게시물의 댓글
  - `seareport`: 위험 알림 `{"kind","text","lat","lng"}` + 사진 0~1장
  - 서버가 게시판마다 최근 100개만 주므로 게시물·알림·댓글도 각각 최근 100개까지만 보임
- 지도는 카카오맵 (길찾기와 같은 JavaScript 키). 등록한 도메인 `https://rudghch.github.io`에서만 보임. 앱 안 미리보기에서는 지도가 안 뜨니 웹에 올린 뒤 확인.
- 바다 정보는 무료 서버 Open-Meteo (키 필요 없음): 수온·파도·물높이는 `marine-api.open-meteo.com`, 바람·기온·날씨·자외선은 `api.open-meteo.com`. 약 5km 칸마다 계산한 **예상값**이고, 육지 칸이면 가까운 바다 칸(`cell_selection=sea`)을 씀. 가끔 대답을 안 해서 한 번 더 물어보게 함.
- 해파리·상어·적조는 키 없이 쓸 수 있는 공개 실시간 정보를 못 찾아서, 친구들이 알리는 "위험 알리기"로 만듦. 공식 사이트 링크(국립해양조사원, 국립수산과학원)만 걸어 둠.
- 나쁜 말 막기(`BAD_WORDS`)는 잉스타·섬지도와 같은 목록. 게시물·댓글·알림에 씀.
- 한 번에 기능 하나씩 만들고, 동작을 확인한 뒤 다음 기능으로 넘어갑니다.
- 실제 서비스의 이름과 로고는 쓰지 않습니다. 서비스 이름은 학생들이 정합니다.
- 개인정보 규칙: 얼굴이 나온 사진, 실명, 전화번호, 집 주소는 넣지 않게 안내함. 이 사이트는 누구나 열 수 있음.

## 학생들이 바꾸기 쉬운 곳 (`index.html`)
- `STORY_KINDS`: 올릴 때 고르는 종류 (섬 풍경, 바다 생물, 어업 도구, 이게 뭐예요?, 기타)
- `SWIM_RULES`: 수영 신호등 기준 (수온 23/20°C, 파도 0.5/1.0m, 바람 7/10m/s, 위험 알림 5km)
- `REPORT_KINDS`: 위험 알림 종류 (해파리, 상어, 적조, 물살이 셈, 쓰레기·유리, 기타)와 신호등 색
- `REPORT_DAYS`: 위험 알림을 며칠 보여 줄지 (3일)
- `BOATS`: 탈것과 빠르기 (카약 3, 요트 6, 여객선 15, 모터보트 25노트)
- `DOCK_WORDS`, `DOCK_RADIUS`: 배를 댈 곳을 찾을 때 카카오맵에 묻는 말과 거리(20km)
- `DOCK_SKIP`: 배 댈 곳 결과에서 뺄 이름 (주차장, 호텔, 웨딩홀 등이 섞여 나와서 넣음)

## 지금까지 만든 것
(기능을 하나 완성할 때마다 여기에 한 줄씩 적기)
- 기본 준비 (2026-10-23): 맨 위 줄(제목, 내 아이디, 로그아웃, 🏠 처음 화면), 로그인·가입 화면. 처음 화면(`../index.html`)에 카드 하나 더함
- 기본 틀 (2026-10-23): 탭 3개. 왼쪽 지도(핸드폰은 위), 오른쪽 칸(핸드폰은 아래). 지도에는 지금 탭의 표시만 보임. 주소 끝(`#story`, `#sea`, `#route`)에 탭을 적어서 새로고침해도 그 탭이 나옴
- ① 🏝️ 섬과 바다 이야기: 사진·영상 6개까지(고르기, 📷 사진 찍기, 🎥 영상 찍기. 사진은 1280px로 줄이고 영상은 30MB까지), 종류, 찍은 곳(지도 누르기, 지금 내 자리, 사진 속 위치 정보), 섬 이름(꼭), 설명 500글자. 목록은 찾기 칸과 종류 버튼으로 거름. 지도에는 동그란 사진 + 종류 표시. 누르면 크게 보기(‹ ›로 넘김, 영상 재생, 지도에서 보기, 내 것 지우기)와 댓글(200글자, 내 댓글 삭제, 5초마다 새로 받음). "❓ 이게 뭐예요?"는 "아는 친구는 답을 달아 주세요" 안내가 보임
- ② 🌊 오늘의 바다: 처음에는 여수 앞바다. 지도 누르기·지금 내 자리로 바꿈. 수영 신호등(🟢🟡🔴)과 까닭, 수온·파도·바람·기온·날씨·자외선, 오늘·내일 물때 그래프(만조·간조 시각, 지금 밀물/썰물). 위험 알리기(종류, 곳, 설명 200글자, 사진 1장)는 지도에 빨간 동그라미로, 목록에 최근 3일치. 고른 바닷가 5km 안의 알림은 신호등에도 들어감
- ③ ⛵ 바다 길찾기: 탈것 고르기(빠르기 바꿀 수 있음), "지도에 길 찍기"로 출발→들르는 곳→도착을 차례로 누름(하나 지우기, 모두 지우기). 구간마다 방향(예: 남동쪽 155°)·거리·시간, 모두 km·해리·걸리는 시간. 도착지 바다 상태(🟢🟡🔴), 도착지 20km 안의 배 댈 곳(카카오 장소 검색, 가까운 8곳, 지도에 ⚓). 곧은 선이라 섬·바위를 피하지 않는다는 안내가 있음
- 시험 (2026-10-23): 가짜 지도·가짜 서버로 세 탭의 올리기·거르기·크게 보기·댓글·나쁜 말 막기·위험 알리기·신호등·길 찍기·배 댈 곳을 확인함. 바다 정보는 진짜 Open-Meteo로 확인함(여수 앞바다 수온 21.5°C, 파도 0.6m, 물때 그래프)
