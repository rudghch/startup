# 길찾기 서비스 (티맵과 비슷한 서비스)

초등학교 6학년 학생들이 직접 기획하고 만드는 길찾기 웹 서비스입니다.
이 폴더에서는 길찾기 서비스만 다룹니다.

## 함께 일하는 사람
- 사용자는 초등학교 6학년 학생입니다. 쉬운 말로 짧게 설명하고, 어려운 용어는 풀어서 말해 주세요.
- 무엇을 바꿨는지, 어디를 눌러 보면 확인할 수 있는지 매번 알려 주세요.
- 요청이 애매하면 마음대로 정하지 말고 한 가지만 되물어 주세요.

## 만드는 방식
- 설치 없이 브라우저에서 바로 열리는 웹 페이지로 만듭니다 (HTML, CSS, JavaScript).
- 지도는 API 키가 필요 없는 무료 오픈 지도(Leaflet + OpenStreetMap)로 시작합니다.
- 한 번에 기능 하나씩 만들고, 동작을 확인한 뒤 다음 기능으로 넘어갑니다.
- 실제 서비스의 이름과 로고는 쓰지 않습니다. 서비스 이름은 학생들이 정합니다.
- 실제 이름, 전화번호, 집 주소 같은 개인정보는 넣지 않습니다.

- 학생이 "올려줘"라고 하면 이 폴더의 변경만 GitHub에 올립니다. 다른 팀 폴더는 건드리지 않습니다.

- 올린 뒤 1~2분 지나면 크롬북에서 새로고침해 확인할 수 있습니다.
