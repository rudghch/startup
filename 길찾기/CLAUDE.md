# 길찾기 서비스 (티맵과 비슷한 서비스)

초등학교 6학년 학생들이 직접 기획하고 만드는 길찾기 웹 서비스입니다.
이 폴더에서는 길찾기 서비스만 다룹니다.

## 함께 일하는 사람
- 사용자는 초등학교 6학년 학생입니다. 쉬운 말로 짧게 설명하고, 어려운 용어는 풀어서 말해 주세요.
- 무엇을 바꿨는지, 어디를 눌러 보면 확인할 수 있는지 매번 알려 주세요.
- 요청이 애매하면 마음대로 정하지 말고 한 가지만 되물어 주세요.

## 만드는 방식
- 설치 없이 브라우저에서 바로 열리는 웹 페이지로 만듭니다 (HTML, CSS, JavaScript).
- 지도는 카카오맵 JavaScript API를 씁니다 (카카오 개발자 앱 "6학년 길찾기", JavaScript 키는 `index.html`에 있음).
- 카카오맵은 등록한 도메인 `https://rudghch.github.io`에서만 보입니다. 앱 안 미리보기에서는 지도가 뜨지 않으니, 지도는 웹에 올린 뒤 확인합니다.
- 카카오맵 무료 사용량 안에서만 씁니다. REST API 키나 어드민 키는 코드에 넣지 않습니다.
- 한 번에 기능 하나씩 만들고, 동작을 확인한 뒤 다음 기능으로 넘어갑니다.
- 실제 서비스의 이름과 로고는 쓰지 않습니다. 서비스 이름은 학생들이 정합니다.
- 실제 이름, 전화번호, 집 주소 같은 개인정보는 넣지 않습니다.

- 경로는 무료 길찾기 서버 OSRM(`router.project-osrm.org`, 자동차 길 기준)에서 받아 옵니다. 키가 필요 없고, 실패하면 곧은 선으로 잇습니다.
- 로드뷰는 화면이 실제로 보일 때만 그려집니다. 앱 안 미리보기나 가려진 탭에서는 회색으로 보일 수 있으니, 크롬 브라우저에서 사이트를 열어 확인합니다.

## 지금까지 만든 것 (이어서)
- 출발·도착 정하기: 이름으로 검색해 목록에서 고르거나, "지도에서 찍기"를 누른 뒤 지도를 눌러서 정함
- 경로 한눈에 보기: 출발과 도착이 정해지면 길을 파란 선으로 그리고, 길 전체가 보이게 지도를 자동으로 축소함. 거리와 자동차 예상 시간을 보여 줌
- 로드뷰 자동 보기: 길을 따라 로드뷰 사진을 2초마다 넘겨 보여 주고, 지금 보는 곳을 지도에 주황색 동그라미로 표시함. 일시정지/이어 보기/처음부터 버튼이 있음. 속도와 간격은 `index.html`의 `STEP_TIME`, `STEP_METERS`, `MAX_STEPS`로 바꿈
