# 씨그널 서비스 (바다 신호등)

바닷가의 지금 상태(수온, 파도, 바람, 물때)를 보고 수영해도 되는지 신호등으로 알려 주는 웹 서비스입니다.
이 폴더에서는 이 서비스만 다룹니다. 같은 날 함께 만든 서비스: `../바다이야기/`, `../바다길찾기/`.

## 함께 일하는 사람
- 사용자는 초등학교 6학년 학생(또는 선생님)입니다. 쉬운 말로 짧게 설명하고, 어려운 용어는 풀어서 말해 주세요.
- 무엇을 바꿨는지, 어디를 눌러 보면 확인할 수 있는지 매번 알려 주세요.
- 요청이 애매하면 마음대로 정하지 말고 한 가지만 되물어 주세요.
- 지금 화면은 "기본 틀"입니다. 학생들이 보고 기능을 더하거나 뺄 예정입니다 (2026-10-23 선생님).

## 서비스 이름
씨그널 (2026-10-23에 "오늘의 바다"에서 바꿈. 폴더 이름과 주소는 그대로 `오늘의바다`)

## 찾은 문제 (2026-10-23)
- 바닷가에 놀러 가면 실시간 정보를 모른다: 물이 언제 차는지(물때), 위험한지, 해파리·상어, 수온, 수영해도 되는지, 적조.

## 만드는 방식
- 설치 없이 브라우저에서 바로 열리는 웹 페이지 (`index.html` 한 파일).
- 로그인은 메신저·잉스타·섬지도와 같은 계정(`messenger.token`). 지금은 서버에 저장하는 기능이 없어서 로그인만 씀.
- 바다 정보는 무료 서버 Open-Meteo (키 필요 없음): 수온·파도·물높이는 `marine-api.open-meteo.com`, 바람·기온·날씨·자외선은 `api.open-meteo.com`. 약 5km 칸마다 계산한 **예상값**이고, 육지 칸이면 가까운 바다 칸(`cell_selection=sea`)을 씀. 가끔 대답을 안 해서 한 번 더 물어보게 함.
- 해파리·상어·적조는 키 없이 쓸 수 있는 공개 실시간 정보가 없음. 공식 사이트 링크(국립해양조사원, 국립수산과학원)만 걸어 둠.
- 주소 끝에 `#위도,경도`를 붙이면 그곳 바다를 보여 줌. 바다 길찾기의 "🌊 도착지 바다 자세히 보기"가 이렇게 보냄.
- 지도는 카카오맵 (길찾기와 같은 JavaScript 키). 등록한 도메인 `https://rudghch.github.io`에서만 보임.
- 한 번에 기능 하나씩 만들고, 동작을 확인한 뒤 다음 기능으로 넘어갑니다.
- 실제 서비스의 이름과 로고는 쓰지 않습니다.

## 학생들이 바꾸기 쉬운 곳 (`index.html`)
- `SWIM_RULES`: 수영 신호등 기준 (수온 23/20°C, 파도 0.5/1.0m, 바람 7/10m/s)
- `CLOSE_LEVEL`: 지도를 누르면 확대할 크기 (2 = 눈금 30m. 1이 가장 크게, 숫자가 클수록 멀리)
- `FIRST_PLACE`: 처음 보여 줄 바다 (여수 앞바다, 위도 34.66 경도 127.70. 예전 자리 34.62, 127.74는 돌산도 땅 위였어서 2026-10-23에 옮김)

## 지금까지 만든 것
(기능을 하나 완성할 때마다 여기에 한 줄씩 적기)
- 기본 틀 (2026-10-23, 처음에는 `새-서비스` 탭 하나였다가 같은 날 따로 나눔): 왼쪽 지도(핸드폰은 위), 오른쪽 칸(핸드폰은 아래)
- 바닷가 고르기: 처음에는 여수 앞바다. 지도를 아무 데나 누르면(버튼 없이도) 그곳 바다를 보여 주고 지도를 2단계(눈금 30m)로 한 번에 확대함. 지금 내 자리도 같은 크기로 확대
- 수영 신호등(🟢🟡🔴)과 까닭, 수온·파도·바람·기온·날씨·자외선, 오늘·내일 물때 그래프(만조·간조 시각, 지금 밀물/썰물)
- 이름을 씨그널로 바꾸고 "위험 알리기"(친구들이 해파리·상어·적조를 알리는 기능)를 뺌 (2026-10-23 선생님). 예전에 쓰던 게시판 `seareport`는 서버에 남아 있지만 이제 쓰지 않음
- 시험 (2026-10-23): 가짜 지도로 지도 누르기(2단계로 확대, 바다 정보 다시 받기)를 확인함. 바다 정보는 진짜 Open-Meteo로 확인함
- 아직 확인 못 한 것: 로그인한 뒤 진짜 카카오 지도에서 확대되는 모습, 핸드폰 내 자리

## 미리보기와 웹에 올리기
- 미리보기: 작업 폴더의 `.claude/launch.json`에 있는 `startup-preview`로 열고 `http://localhost:8765/오늘의바다/`로 감. 지도는 안 뜸.
- 다 만들면 묻지 않고 GitHub에 올림 (선생님 요청, 2026-10-23).
  - 주소: https://rudghch.github.io/startup/오늘의바다/
  - `git add .` (이 폴더 안에서 실행) → `git commit -m "씨그널: 바꾼 내용 한 줄"` → `git push`
  - `git`을 찾지 못하면 `C:\Program Files\Git\cmd\git.exe`를 씀. 이 폴더의 변경만 올리고, 다른 팀 폴더는 건드리지 않음.
