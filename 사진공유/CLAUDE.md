# 사진공유 서비스 (인스타그램과 비슷한 서비스)

초등학교 6학년 학생들이 직접 기획하고 만드는 사진 공유 웹 서비스입니다.
이 폴더에서는 사진공유 서비스만 다룹니다.

## 함께 일하는 사람
- 사용자는 초등학교 6학년 학생입니다. 쉬운 말로 짧게 설명하고, 어려운 용어는 풀어서 말해 주세요.
- 무엇을 바꿨는지, 어디를 눌러 보면 확인할 수 있는지 매번 알려 주세요.
- 요청이 애매하면 마음대로 정하지 말고 한 가지만 되물어 주세요.

## 만드는 방식
- 설치 없이 브라우저에서 바로 열리는 웹 페이지로 만듭니다 (HTML, CSS, JavaScript).
- 첫 버전은 서버 없이 한 컴퓨터 화면 안에서 동작합니다. 올린 사진은 그 컴퓨터에서만 보입니다.
- 한 번에 기능 하나씩 만들고, 동작을 확인한 뒤 다음 기능으로 넘어갑니다.
- 실제 서비스의 이름과 로고는 쓰지 않습니다. 서비스 이름은 학생들이 정합니다.
- 실제 이름이나 얼굴이 나온 사진 같은 개인정보는 넣지 않습니다. 예시 사진은 풍경, 음식, 그림 등을 씁니다.
