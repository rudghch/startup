# 사진공유 서비스 (인스타그램과 비슷한 서비스)

초등학교 6학년 학생들이 직접 기획하고 만드는 사진 공유 웹 서비스입니다.
이 폴더에서는 사진공유 서비스만 다룹니다.

## 함께 일하는 사람
- 사용자는 초등학교 6학년 학생입니다. 쉬운 말로 짧게 설명하고, 어려운 용어는 풀어서 말해 주세요.
- 무엇을 바꿨는지, 어디를 눌러 보면 확인할 수 있는지 매번 알려 주세요.
- 요청이 애매하면 마음대로 정하지 말고 한 가지만 되물어 주세요.

## 만드는 방식
- 설치 없이 브라우저에서 바로 열리는 웹 페이지로 만듭니다 (HTML, CSS, JavaScript).
- 계정과 사진은 AWS 서버에 저장합니다. 그래서 올린 사진이 다른 컴퓨터에서도 보입니다.
- 한 번에 기능 하나씩 만들고, 동작을 확인한 뒤 다음 기능으로 넘어갑니다.
- 실제 서비스의 이름과 로고는 쓰지 않습니다. 서비스 이름은 학생들이 정합니다.
- 실제 이름이나 얼굴이 나온 사진 같은 개인정보는 넣지 않습니다. 예시 사진은 풍경, 음식, 그림 등을 씁니다.

## 지금까지 만든 것
(기능을 하나 완성할 때마다 여기에 한 줄씩 적기)
- 사진 올리기와 목록: 사진을 여러 장 골라 올리고, 목록에서 한 장씩 삭제함 (`index.html` 한 파일)
- 서버 연결 (2026-10-06): 메신저 팀과 같은 AWS 서버, 같은 계정을 씀. 아이디+비밀번호로 로그인하거나 가입함 (가입할 때 가입 코드 필요). 메신저에서 로그인해 두면 잉스타도 바로 들어가짐. 사진은 1280px로 줄여 서버에 올리므로 다른 컴퓨터에서도 보임. 누가 올렸는지 보이고, 내가 올린 사진만 삭제할 수 있음. 게시판 이름은 `instar`
- 서버를 만든 파일과 설명서는 공개 폴더 밖 `클로드코드\메신저-서버-준비\`에 있음. 서버 주소는 `index.html`의 `API_URL`
- 서버 연결 전에 그 컴퓨터에만 저장했던 예전 사진은 이제 화면에 나오지 않음
- 이동 링크: 로그인한 뒤에도 맨 위 오른쪽에 "처음 화면"과 "message"로 가는 링크가 보임 (message에도 "처음 화면"과 "잉스타" 링크를 넣음)
- 크게 보기 (2026-10-06): 목록에서 사진을 누르면 창이 떠서 크게 보임. "닫기", 창 바깥, Esc로 닫음
- 좋아요와 댓글: 크게 보기 창 안에서 누르고 씀. 좋아요는 한 번 더 누르면 취소되고 몇 명이 눌렀는지 보임. 댓글은 200글자까지, 내 댓글만 삭제. 창이 열려 있는 동안 5초마다 새로 받아 옴
- 게시물 (2026-10-06): "＋ 새 게시물" 창에서 글(500글자까지)과 사진(10장까지)을 함께 올림. 글만, 사진만도 됨. 목록 카드에는 첫 사진과 "사진 N장" 표시, 그 아래 글이 보이고, 글만 있는 게시물은 글이 사진 자리에 크게 보임. 크게 보기 창에서 ‹ › 로 사진을 넘김
- 목록의 좋아요 수·댓글 수: 카드 아래에 `♡ 수 💬 수`로 보임. 카드가 화면에 보일 때만 서버에 물어보고(한꺼번에 4개까지), 30초마다 다시 물어봄
- 나쁜 말 막기: `BAD_WORDS`(message와 같은 목록)에 있는 말이 들어 있으면 게시물 글·댓글·답글이 올라가지 않고 안내가 나옴. 다른 길로 올라온 나쁜 말 댓글은 통째로 가려서 보여 줌
- 답글과 댓글 좋아요: 댓글마다 "♡ 좋아요", "답글 달기", "답글 N개"가 보임. 답글은 댓글 아래 안쪽에 보이고, 답글에 또 답글은 달 수 없음. 지워진 댓글의 답글은 안 보임
- 프로필: 맨 위 오른쪽의 내 아이디 버튼을 누르면 프로필 사진을 고르거나 기본 그림(아이디 첫 글자)으로 되돌림. 사진 카드와 댓글에 올린 사람의 프로필 사진과 아이디가 함께 보임. message에는 아직 프로필 사진이 안 보임
- 서버는 고치지 않고 게시판 이름만 나눠 씀: 프로필 사진은 `instarprofile`(계정마다 가장 새것 하나), 좋아요는 `l`+사진 번호, 댓글은 `c`+사진 번호 (사진 번호의 숫자를 0→a … 9→j 글자로 바꿈). 게시판 하나에서 최근 100개까지만 받아 오므로 사진 한 장에 좋아요·댓글 100개, 프로필 사진 100명까지. 사진을 지워도 그 사진의 좋아요·댓글은 서버에 남음
- 같은 방법으로 더 나눠 쓰는 것: 댓글 좋아요는 `k`+게시물 번호 게시판(글에 댓글 번호를 적음). 답글은 댓글 게시판에 같이 넣고 글 앞에 `\u0001r댓글번호\u0001`을 숨겨 적음. 서버는 글 하나에 사진 6장까지만 받으므로 7번째 사진부터는 `x`+아무 글자 19개 게시판에 따로 올리고, 게시물 글 끝에 `\u0001m게시판이름\u0001장수`를 숨겨 적음. 댓글+답글은 게시물 하나에 합쳐서 100개까지
- 프로필 화면 (2026-10-06): 카드·댓글·크게 보기 창의 프로필 사진이나 아이디를 누르면 그 사람의 프로필 사진, 아이디, 자기소개와 그 사람이 올린 게시물만 보임. "← 모든 게시물 보기"로 돌아감. 맨 위 오른쪽 내 아이디 버튼은 내 프로필 화면으로 가고, 거기서 "프로필 바꾸기"를 누르면 사진과 자기소개(100글자)를 바꿈. 자기소개는 `instarbio` 게시판(계정마다 가장 새것 하나). 서버에서 최근 게시물 100개만 받아 오므로 프로필 화면도 그 안에서만 골라 보여 줌
- 영상: 게시물에 사진과 영상을 섞어 10개까지 올림. 영상은 줄이지 않고 한 개에 30MB까지. 카드에는 첫 장면과 "▶ 영상" 표시, 크게 보기 창에서 재생
- 바로 찍기: 새 게시물 창의 "📷 바로 찍기"는 `capture`가 붙은 파일 칸이라 핸드폰에서는 카메라가 바로 열림. 컴퓨터에서는 파일 고르는 창이 열림
- 수정: 내 게시물은 카드의 "수정"으로 글만 고침(사진·영상은 못 바꿈). 내 댓글·답글은 "수정"을 누르면 댓글 칸에서 고치고 "(수정됨)"이 붙음. 서버에 고치는 기능이 없어서 원래 것은 그대로 두고 고친 글을 따로 올림: 게시물은 `e`+게시물 번호 게시판에 `\u0001e고친글`, 댓글은 댓글 게시판에 `\u0001e댓글번호\u0001고친글`. 쓴 사람이 올린 가장 새것만 믿음
- 초성 욕 막기: `BAD_WORDS`에 ㅈㄲ, ㄴㅇㅁ, ㄳㄲ, ㄱㅅㄲ, ㅅㄲ, ㅄ, ㄴㄱㅁ, ㅁㅊㄴ, ㄲㅈ, ㄷㅊ 등을 더함 (ㅅㅂ, ㅈㄹ 등은 전부터 있었음). 자기소개에도 적용. message의 목록은 고치지 않았음
- 아직 확인 못 한 것: 진짜 영상 파일 올리고 재생하기, 핸드폰에서 카메라가 열리는지 (가짜 서버와 가짜 파일로만 시험함)
- 아직 확인 못 한 것: 진짜 서버에 가입하고 게시물을 올리는 것, 진짜 서버에서 좋아요·댓글·답글·프로필 (가짜 서버로만 시험함. 가입 코드를 Claude가 몰라서 학생이 직접 해 봐야 함). 새 화면 모양을 눈으로 보는 것과 목록의 좋아요 수가 저절로 채워지는 것도 못 봄 (시험할 때 미리보기 화면이 그려지지 않았음)
